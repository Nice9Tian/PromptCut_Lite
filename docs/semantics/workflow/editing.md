# 编辑界面：查看与修正

展开 `../user-workflow.md` 主线的第 3 步「用户实时查看」和第 4 步「用户交互修正」，以及编辑界面本身。从属于 `user-workflow.md`，与它冲突时以它为准。

## 编辑界面

- 左栏（素材、动画、特效、编辑、字幕）+ 预览 + 时间轴 + AI 栏。
- 左栏和时间轴可收起，收起后只剩预览和 AI 栏。
- 皮肤：界面外观可切换。
- 界面风格：整体圆角；遵循 Microsoft Fluent Design 规范的现代深色生产力工具风格；主题色是高饱和度的青蓝色和低饱和度的酱紫色。

## 用户实时查看

- 预览显示时间轴某一刻的画面，可播放、暂停、拖动。
- AI 栏显示 Agent 的进度条目和操作详细预览：看过的图、改动前后的动图、参数差异。

## 用户交互修正

用户可以再发一条指令，也可以自己动手：

- 时间轴：拖动、改时长、切分、换序列、吸附、序列换序、多条剪辑版本切换。
- 剪辑标签（2026-10-20 用户定）：时间轴上方为每条打开过的剪辑留一个标签，点标签切换激活的剪辑。标签不会因为失去焦点或点了别处而消失，一直留着，直到用户点标签上的「×」关掉；「×」只关标签，不删剪辑。最后一个标签不能关。删除剪辑在素材库里做。
  - 剪辑的入口只有素材库的「剪辑」组和这一栏标签两处；双击标签改名，标签栏末尾可以新建剪辑；双击时间轴上的剪辑段，在标签栏里打开并激活它引用的剪辑。剪辑被删掉（包括 Agent 删的）时它的标签自动消失。
  - 打开了哪几个标签是这台设备上的界面状态：刷新、重开项目后恢复（存法在 `../mechanism/project-model.md`）。
- 剪辑段的属性（2026-10-21 用户定）：选中剪辑段时，编辑分区可以改从被引用剪辑的第几秒开始，以及框、不透明度、淡入淡出、音量和静音；引用哪条剪辑不能改，要换就删掉这段，从素材库重新拖一条。打开被引用的剪辑：双击剪辑段，或在右键菜单点『打开剪辑』；编辑分区里也有『打开被引用剪辑』按钮。
- 片段速度（2026-10-23 用户定）：选中一个素材段时，编辑分区里有「速度」一栏。可以点常用倍率，也可以手动输入，范围 **0.25～4 倍**；超出范围**拒绝并提示**「速度要在 0.25～4 倍之间」，项目一点不改，不悄悄夹到边界。
  - 改了速度，这一段跟着变长变短：**变短**时挂在它上面的转场跟着缩短（短到装不下才拒绝这次改速度）；**变长**时推开后面的片段，推不开（后面的段在锁定的序列上，或推过去仍重叠）则**整个操作不生效并说明原因**，不截断、不部分生效。
  - 变速的声音会**变调**（2 倍高八度、0.5 倍低八度）；保调变速记在待办里。
  - 变速的素材段**可以**当音频素材效果卡的声音输入（2026-10-23 用户放开）；自带画面和声音的卡挂在变速段上也照常出声（2026-10-23 用户定）。

- AI 栏的 Agent 标签（2026-10-20、2026-10-22 用户定）：
  - 每个 Agent 标签都可以关闭，包括第一个「Agent 1」和最后一个，悬停出「×」；关掉当前标签后切到相邻的标签。新建标签取当前最小的空号（关掉「Agent 2」后再新建得到「Agent 2」，不是「Agent 4」）。
  - 分页清单按项目分开（2026-10-22 用户定）：每个项目有自己的一份 Agent 标签，切换项目就换成那个项目自己的那一份；界面上叫 Agent 1、Agent 2……，编号只在本项目内取最小空号；代码里标签的标记（存储的键、内部 id）是「项目ID_AgentID」。
  - 没有会话时显示开始页（2026-10-22 用户定）：
    - 本项目一个会话都没有时（刚进项目，或用户把会话全关光了），AI 栏显示开始页：一个编辑框（平时的输入框）和一个预设按钮「做一个动画告诉我使用软件可以干什么」。点预设，这句话放进编辑框，发送按钮闪动，引导用户点发送。用户点发送之前不建会话、不发出聊天消息；点发送后才建第一个 Agent 会话（Agent 1），这条消息在里面发出。
    - 刚进项目、本项目从来没被用户手动关光过会话：开始页带引导动画，引导用户在输入框里写，或点预设。用户手动把会话关光之后（按项目记），这个项目的开始页不放引导动画，只有预设和编辑框。
    - 开始页在右栏竖栏里是一项「开始」（没有「×」），没有会话时「+」就是回到它；引导动画是一个呼吸的光点、指向输入框的向下箭头、输入框的描边脉动，克制，用现有深色与青蓝强调色；系统设了「减少动态效果」时动画全部关掉，只留静态描边；点预设后发送按钮闪动在两种开始页里都有（不是引导动画的一部分）；「手动关光过」记在本机浏览器里，不进项目文件。
- 预览：选中、移动、改文字、右键引用到 AI 或删除。
- 编辑分区：参数表单、约定封装的代码页、节点图。
- 字幕：在时间轴上逐条拖动、改时长、双击改字。
- 撤销、重做。按撤销遇到之后被 Agent 或自己改过的冲突时，可弹出「冲突合并」窗口（2026-10-18 用户定）：
  - **导航栏常驻入口**：只要存在待处理的冲突或待合并项，软件导航栏顶端就显示「冲突合并」按钮，用户随时可以打开处理；全部处理完后按钮隐藏。
  - **两级可勾选列表**：一级条目按被改的那样东西列，时间轴上的每个片段（卡片段、素材段、剪辑段）、每条字幕、每张卡片的源码、项目设置各算一条；展开到二级是它被改的各个属性，同一个属性改了几次只列一条。展开后可单独勾选其中某一项。
  - **顶端按钮**：「选中无冲突项」「取消全部勾选」。
  - **底部按钮**：「合并」（应用选中项）、「删除选中」（丢弃选中项），以及关闭按钮——当列表里还有可选项时显示为「下次再说」，当没有任何可选项时变成「完成」（规则见 `../product/document-service.md`「冲突」）。
- 一次输入、一次拖动只算一步改动（2026-10-20 用户定）：在数字框里输入一个值，或拖一次滑块，只算一步改动、只记一步撤销，输入过程中的中间值不落进项目。数字框按回车或失去焦点时才算输入完成，按 Esc 放弃；用方向键或框自带的上下箭头连续步进，也合并成一步。滑块拖动中画面可以实时跟着变，整次拖动（按下到松开）合成一步撤销。

## 片段声音（2026-10-05 用户确认）

- 带声音的动效卡片与普通音视频素材都可以单独静音或恢复声音，画面不受影响。
- 时间轴片段显示醒目的「已静音」标记；窄片段仍有常驻图标，序列行头显示静音数量或整条序列静音提示，不要求用户打开属性面板才能发现。
- 动效卡片的参数面板显示声音生成状态，可生成、重生成或取消；声音留在同一个视觉片段中。
- 对内嵌声音的动效卡执行音轨分离，界面明确显示失败原因，Agent 获得结构化失败。多选分离任一项失败，整批不修改。普通视频素材仍按原有流程分离。
